# European Migration Explorer (Artifact)

This repository contains the interactive research artifact for the EMN Country Factsheets (2012–2024). REVIEW MODE

## How to View the Artifact

To inspect and explore the interactive application:

1. Click on the **`index.html`** file in the repository list above.
2. Click **Download raw file** (or open/preview it directly in your browser).
3. Open `index.html` in any web browser (Chrome, Firefox, Safari, or Edge).
